## 📅 时间规划（总计约 30-42 周 / 7-10 个月）

### 🔵 第一阶段：打基础（第1-3个月）

| 周次 | 学习内容 | 目标 |
|------|---------|------|
| 第1-2周 | Python 基础语法 | 变量、数据类型、条件、循环、函数 |
| 第3-4周 | Python 进阶 | 面向对象、文件操作、异常处理、装饰器 |
| 第5-6周 | Python 实战 | 常用库(os/json/re/unittest)、小项目练习 |
| 第7-8周 | Pytest + Requests | 框架核心用法、fixture、参数化 |
| 第9-10周 | 接口自动化实战 | 完整接口自动化项目、Allure报告 |
| 第11周 | Git + Linux | 版本控制、常用命令 |
| 第12周 | CI/CD + Docker 入门 | Jenkins/GitHub Actions 流水线 |

### 🟢 第二阶段：核心能力（第4-6个月）

| 周次 | 学习内容 | 目标 |
|------|---------|------|
| 第13-14周 | Selenium/Playwright | Web UI 自动化 |
| 第15-16周 | PO模式 + 框架搭建 | 企业级UI自动化框架 |
| 第17-18周 | MySQL | SQL查询、多表联查、索引 |
| 第19周 | Redis | 缓存原理、测试中应用 |
| 第20-21周 | JMeter/Locust | 性能测试入门 |
| 第22-23周 | 性能测试实战 | 完整压测方案、瓶颈分析 |

### 🟡 第三阶段：进阶提升（第7-10个月）

| 周次 | 学习内容 | 目标 |
|------|---------|------|
| 第24-27周 | FastAPI 后端开发 | 接口设计、数据库操作、认证 |
| 第28-30周 | Vue.js 前端开发 | 组件、路由、Element Plus |
| 第31-32周 | 测试平台项目 | 完整测试平台开发 |
| 第33-34周 | 安全测试 | OWASP Top10、Burp Suite |
| 第35-38周 | 大模型应用开发 | LLM API、RAG、Agent |
| 第39-42周 | 进阶专题 | K8s、监控、架构设计 |
