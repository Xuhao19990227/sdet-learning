# 1.2 RESTful API 设计规范 · 知识点

> 交付模式：📖 自学资料（2026-10-26 学生定「常识课」规则：只发知识点、不布置作业；进度记「自学未验收」）
> 复审触发器：11 月中首场模面 = 「读资料能过口头面试」假设开牌日，自学课内容照面试标准抽问
> 面试常考点在最后一节——时间不够只读那节

**核心思想一句话**：用 **URI 表示资源**、**HTTP 方法表示操作**、**状态码表示结果**。接口测试三件套正好对上：看资源名（测谁）、看方法（干什么）、看状态码（成没成）。

## 1. 资源与 URI 命名

- URI 是**名词**（资源），不是动词（操作）：✅ `/cases`、`/cases/TC001`、`/users/42/orders`；❌ `/getCaseList`、`/deleteCase`
- 集合用**复数**，层级表达从属：`/users/42/orders` = 42 号用户的订单集合
- 操作交给方法表达：POST /cases = 创建（而不是 POST /createCase）
- 查询参数做过滤/分页，不做资源定位：`/cases?level=P0&page=2`

## 2. 方法语义

| 方法 | 语义 | 幂等 |
|---|---|---|
| GET | 读取，无副作用 | ✅ |
| POST | 创建（或触发动作） | ❌ 十次=十条 |
| PUT | **全量替换** | ✅ |
| PATCH | 局部更新 | 不一定 |
| DELETE | 删除 | ✅ |

- 幂等 = 做一次与做 N 次对资源状态效果相同；PUT 的幂等指同一份完整 body 发两遍，状态不变
- **PUT vs PATCH**（面试高频）：PUT 送完整资源、服务器整个替换；PATCH 只送要改的字段、服务器合并。demo 的 PUT 用 `.update()` 合并 = **PATCH 语义穿了 PUT 的名字**（1.1 作业埋点之一）

## 3. 状态码规范（REST 的结果语言）

- **200** 通用成功 ｜ **201** POST 创建成功（规范应带 Location 头指向新资源）｜ **204** 成功无响应体（DELETE 常用）
- **400** 请求本身错（坏 JSON/缺必填）｜ **401** 未认证（没带/无效/过期凭证——「未授权」名不副实）｜ **403** 认证了但无权限 ｜ **404** 资源不存在（两种：路径不存在 vs 资源不存在）｜ **409 Conflict** 状态冲突（创建已存在的 id 就该回它）｜ **405** 路径在、方法不支持 ｜ **422** 格式对但语义校验失败（FastAPI/Pydantic 先于业务代码）
- **500** 服务端异常穿透（规范服务应回 400 的场景回了 500 = 缺入参校验，本身是 bug）｜ **502/504** 网关收到无效上游响应 / 上游超时（先看链路）

## 4. 判断力案例三条（demo 的三处「不规范」——面试判断题就是这个问法）

1. **凭证错回 403**：惯例是认不出身份一律 **401**，403 留给「知道你是谁但不让干」。错用会误导排查方向（查权限 vs 查凭证）——真实系统遇到，值得提建议单。401 排查序：**带没带**（头名拼写/Bearer 前缀/多空格）→ 过期没 → 环境错没错，先查最便宜的
2. **PUT 实现成合并（.update()）**：调用方对「没送的字段是清空还是保留」产生分歧，两个团队按两种理解调用同一接口，测试断言没法写。**实现与文档不一致本身就是缺陷**——要么改实现要么改文档
3. **POST 已存在 id 回 201 静默覆盖**：标准 REST 应回 **409**；静默覆盖在金融场景 = 数据事故（新单覆盖旧单）——这在面试里叫幂等与并发意识

## 5. 面试常考点（背这节）

- **「谈谈对 RESTful 的理解」** → 三件套：资源（URI 名词）/操作（方法）/结果（状态码），收尾加一句幂等
- **「PUT 和 PATCH 区别」** → 全量替换 vs 局部更新 + 幂等性
- **「409 什么场景」** → 创建冲突（重复 id）、状态冲突（对已完成订单再取消）
- **「404 怎么排查」** → 先分两种：路径不存在（路由/网关）vs 资源不存在（业务），再查环境与参数
- **「接口返回 200，测试就算过了吗」** → 不算：200 ≠ 业务成功（业务码/响应体才是断言对象）
- **追问陷阱：「你们公司接口是 RESTful 吗」** → 诚实口径：自研平台偏 RPC 风格（动词路径常见），能说出它和 REST 的差别在哪——**指出不规范，比背规范更加分**
