# 碎片时间学习清单（输入型学习）

> 建档：2026-09-12。原则：**家里整块时间 = 输出（写代码/项目/练习）；上班碎片时间 = 输入（读/背/想）**。
> 两边互补不互抢；每天碎片合计 ≤1 小时；本清单不改变每周 10-15h 主计划，是加餐不是第二课堂。

---

## ❌ 不适合碎片时间的（留给家里）

- 写练习代码、做周项目（需要调试环境和长专注，被打断成本极高）
- 视频课（扎眼 + 被动输入效率低）
- 任何需要跑 venv 的东西

## ⚠️ 红线（职业素养，违反会伤害整个转岗计划）

1. **主业质量不能掉** —— 岗位 = 现金流 + 背调记录 + 面试素材来源，这是你计划的地基
2. **个人学习代码不上公司电脑、公司 git**；公司的接口文档、数据、代码**一律不外带**
3. **迁移项目原则：上班学思路，回家做实现** —— 用公开 API 或 mock 数据重写同等复杂度的场景，个人仓库里不出现公司资产（11-12 号那次隐私文件泄露演练的教训，同一个逻辑）
4. 低调、可快速切换、不向同事传播学习节奏
