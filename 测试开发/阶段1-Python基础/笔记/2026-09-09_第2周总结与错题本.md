## 一、知识要点速查

### 2.1 条件判断（if/elif/else）
- `if` / `elif` / `else` 多分支，从上往下匹配，命中即跳出
- 条件表达式结果是 bool：`==`、`!=`、`>`、`<`、`in`、`not in`
- 嵌套 if 不超过 3 层，深了考虑提前 return 或 elif 扁平化

### 2.2 循环（for / while / break / continue）
- `for x in 序列`：遍历 list/str/range/dict
- `while 条件`：适合"不知道循环几次"的场景（菜单系统）
- `break` 跳出整个循环；`continue` 跳过本次进入下一次
- `range(start, end, step)`：左闭右开，跟切片一样

### 2.3 列表（list）
- 增：`append()`（尾部加一个）、`insert(i, x)`（指定位置）、`extend()`（合并）
- 删：`remove(值)`、`pop(索引)`、`del list[i]`
- 改：`list[i] = 新值`
- 查：`in`（是否存在）、`index()`（找位置）、`count()`（计数）
- 切片：`list[start:end:step]`，左闭右开
- 推导式：`[表达式 for x in 序列 if 条件]`
- 排序：`sorted()` 返回新列表；`.sort()` 原地改（返回 None！）
- 常用函数：`len()`、`max()`、`min()`、`sum()`

### 2.4 元组（tuple）与集合（set）
- tuple：不可变列表，用 `(a, b, c)` 或 `a, b, c` 创建；单元素加逗号 `(x,)`
- tuple 解包：`a, b, c = my_tuple`
- set：无序、不重复，`{1, 2, 3}` 或 `set(list)`
- set 运算：`&` 交集、`|` 并集、`-` 差集
- **dict 的 key 和 set 的元素必须是不可变类型**（str/int/tuple，不能是 list）

### 2.5 字典（dict）
- 创建：`d = {"key": value}` 或 `dict(key=value)`
- 取值：`d["key"]`（不存在报 KeyError）、`d.get("key", 默认值)`（安全）
- 增/改：`d["key"] = value`（key 存在则改，不存在则增）
- 删：`d.pop("key")`、`del d["key"]`
- 判断：`"key" in d`
- 遍历：`for k, v in d.items()`（最常用）、`.keys()`、`.values()`
- 嵌套钻取：`d["a"]["b"]["c"]`，安全写法 `d.get("a", {}).get("b", {}).get("c", 默认)`
- 计数器模式：`d[key] = d.get(key, 0) + 1`
- 保序去重：`list(dict.fromkeys(items))`（set 会丢顺序！）

### 2.6 数据结构选型
| 结构 | 特点 | 典型场景 |
|---|---|---|
| list | 有序、可重复、可变 | 用例列表、结果序列 |
| tuple | 有序、不可变 | 单条记录、函数多返回值 |
| set | 无序、不重复 | 去重、交并差运算 |
| dict | 键值对、快速查找 | 接口响应、配置、统计数据 |

## 四、💡 最佳领悟

> **set 去重会丢顺序**：需要"去重 + 保序"时，用 `dict.fromkeys()` 或手动 `not in` 判断。
> 
> **假阳性是最危险的 bug**：`/3` 恰好等于学生人数时结果对了，但逻辑是错的。测试时**必须用不同数量的数据验证**（2 个学生、3 个学生、0 个学生）。
>
> **计数器模式** `d[key] = d.get(key, 0) + 1`：dict 计数万能公式，以后写框架统计结果天天用。
