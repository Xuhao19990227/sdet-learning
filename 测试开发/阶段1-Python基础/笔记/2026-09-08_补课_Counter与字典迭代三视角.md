## 一、知识要点速查

### 1. 平均数
- `statistics.mean(列表)`：标准库，空列表抛 `StatisticsError`（要判空）
- `sum(列表) / len(列表)`：手写版，空列表 `ZeroDivisionError`
- `numpy.mean()`：大数据量场景，需安装

### 2. Counter（collections 模块）
- `Counter(可迭代对象)` → 特殊字典：键=元素，值=出现次数
- **不存在的键返回 0，不报 KeyError**（与普通字典的区别）
- `most_common(n)`：次数最多的前 n 个，返回 `[(元素, 次数), ...]`；空 Counter 返回 `[]`，直接 `[0]` 会 IndexError
- `total()`：次数总和（3.10+）

### 3. dict.fromkeys(keys, value)
- 拿一批键批量造字典，值统一为 value（不传则全为 None）
- 用途：计数前初始化所有键，之后可直接 `d[k] += 1`，不用 `.get()` 兜底
- ⚠️ **大坑**：value 是可变对象（`[]`/`{}`）时，所有键**共享同一个对象**，改一个全变

### 4. 字典迭代三视角（本次口试重点）
```python
list(d)          # 键（= list(d.keys()) 的简写，"字典不吭声，默认给你键"）
list(d.values()) # 值
list(d.items())  # [(键, 值), ...] 键值对元组，"一对一对地拿"
```
- 顺序：Python 3.7+ 字典保持**插入顺序**（口试中此点答对 ✅）
- `for k, v in d.items()` 的解包 = 拆的就是 items 里的元组
- `d.items()[1][0]` 类嵌套索引：先取第 1 个元组，再取元组第 0 个元素

### 5. 去重且保持顺序的惯用法（lesson6 里自己悟出来的，表扬 🌟）
```python
list(dict.fromkeys(names))   # 去重 + 保持首次出现顺序
sorted(list(set(names)))     # 去重但顺序被打乱，需再排序
```
原理：字典键天然不重复 + 字典保持插入顺序。
