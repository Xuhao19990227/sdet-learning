## 一、知识要点速查

### 3.1 ~ 3.4 函数
- `def` 定义 / 调用；`return` 单值与多值（多值 = 元组解包接收）
- 参数五形态：位置参数、关键字参数、默认值（必须不可变）、`*args`（收成元组）、`**kwargs`（收成字典）——面试必考
- 作用域 LEGB；函数内改全局计数要 `global`（或改成传参+返回，更推荐）

### 3.5 lambda
- 单表达式匿名函数；主战场是当 `key` / 谓词：`sorted(x, key=lambda r: r[2])`、`filter(lambda r: r[1] == "FAIL", records)`

### 3.6 模块与包
- `import` / `from...import` / `as`
- `if __name__ == '__main__':` 防护——**本周实测证明**：导师 `import week3_project` 做边界测试，主流程零执行、零副作用

### 3.7 内置函数四件套
- `enumerate(seq, start=1)`：给**一个**序列编号 → `(序号, 元素)`
- `zip(a, b)`：把**两个**序列按位置配对 → `(a1,b1), (a2,b2)...`，**长度不等按最短截断**
- `map(func, seq)` / `filter(pred, seq)`：惰性迭代器，要 `list()` 落地
- 三区分（本周最重要概念表）：**enumerate 编号一个序列 / zip 配对两个序列 / 解包拆一个元组**

### 文件操作速成（5.1 预热）
- `with open(path, mode, encoding='utf-8') as f:`——自动关文件；**Windows 默认 GBK，encoding 必须显式写**
- 模式：`r` 读 / `w` 覆盖清空（幂等）/ `a` 追加；不存在时 w、a 自动创建，r 报 FileNotFoundError
- `write()` 不自动换行；`writelines()` 也不加换行（名字骗人）
- 读三姿势：`for line in f`（大文件首选）/ `readlines()` / `read()`；行尾 `\n` 用前 `strip()`

## 四、💡 最佳领悟

1. **两个 bug 能互相抵消出"完美输出"**——只核对终端回显会被骗，必须核对交付物本身（速成R3 实录）
2. **对照表假勾比不填表更危险**——✓ 必须能指向真实代码行号，行号就是证据
3. **zip / enumerate / 解包三区分**：编号一个序列 / 配对两个序列 / 拆一个元组
4. **异常类型表达意图**：ValueError=传入值不合法（病因），ZeroDivisionError=算术爆炸（症状）；手写防御必须比自然崩溃**传递更多信息**，否则不如不写
5. **`__name__` 防护的价值被实测证明**：导师 import 模块跑边界测试，主流程零触发
6. **纯计算与 IO 分离**：纯计算函数喂手工列表即可断言，不碰磁盘——单元测试的根基（学生答"降低认知负荷"，导师补"可测试性"）
