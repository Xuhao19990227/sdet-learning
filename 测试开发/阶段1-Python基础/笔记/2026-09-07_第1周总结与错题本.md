## 一、知识要点速查

### 1.3 运算符
- `/` 结果永远是 float；`//` 整除向下取整；`%` 取余（`//` 和 `%` 是换算分秒/毫秒的搭档）
- 链式比较：`60 <= score < 90`
- `and` / `or` / `not` 组合条件，断言的雏形：`status_code == 200 and cost < 1`
- **Python 没有 `++` / `--`**，只能 `count += 1`
- bool 是 int 的子类：`True + True == 2`，`sum([ok_a, ok_b, ok_c])` 可统计达标数

### 1.4 字符串
- 切片 `s[start:end:step]`：**左闭右开**（不含 end）；`[::-1]` 反转（面试必考）
- f-string 四板斧：`:.2f` 小数、`:.1%` 百分比、`:,` 千分位、`:<10` 对齐
- 字符串**不可变**：方法返回新串，必须 `s = s.upper()`
- `split` ↔ `join` 互为反操作；`find` 找不到返回 -1，判断存在用 `in`
- `replace` 严格逐字符匹配，方括号空格都算字符
- 汉字对齐坑：一个汉字占两格宽，Python 只按 1 个字符算

### 1.5 输入输出
- **`input()` 永远返回 str**（面试必考），数字要 `int()` / `float()` 转换
- `print` 的 `sep` 管中间分隔，`end` 管行尾（默认换行 `\n`）
- 非法输入会让 `int()` 崩溃（ValueError）→ 5.2 异常处理解决

## 四、💡 最佳领悟
