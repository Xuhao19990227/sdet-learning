## 一、知识要点速查（4.1 ~ 4.5）

### 4.1 类与对象
- `class` / `__init__` / `self`：self 由 Python 自动传入，代表"调用这个方法的那个实例"
- **方法引用 vs 方法调用**：`x.is_p0` 是名片（恒真），`x.is_p0()` 才是值——本周在阶段 B 又栽两轮（见错题本）

### 4.2 属性与方法
- 实例属性（`self.xxx`）vs 类属性（类体里直接赋值，全体共享）
- 计数器口诀：**读走继承链，`self.xxx =` 写落实例**——类属性计数必须 `Cls.count += 1`
- `@classmethod` 工厂（`from_csv_line`，cls=发起调用的类，天然支持子类）；`@staticmethod` 谓词校验（契约：说返回 bool 就返回 bool，不许 raise/永真）

### 4.3 继承
- 单继承 + 方法覆盖（子类 `run()` 顶掉父类）；`super().__init__()` 委托初始化
- 彩蛋：不调 super 连父类计数也不加；`isinstance` / `issubclass`

### 4.4 多态与封装
- **决定跑哪个 `run()` 的不是代码写在哪个类，而是 `self` 是谁**——查找从实例的类开始沿 MRO 向上
- 封装：私有属性（`__records` → 名称改写 `_Report__records`）+ 受控的门（add/summary）
- 鸭子类型：PerfCase 没继承也能混跑 batch_run；**开闭原则**：扩展开放（新 case 类）、修改关闭（batch_run 禁 isinstance）——学生自发说出精髓 🌟

### 4.5 魔术方法
- `__str__`（用户视角）/ `__repr__`（开发者视角，用 `!r`，print 列表时元素回退 `__repr__`）/ `__len__`（必须返 int，否则 `len()` TypeError）/ `__eq__`（自定义相等语义）
- **魔术方法由语法触发，不由手调用**：写 `len(self)`，不写 `self.__len__()`

### 周练习（OOP 重构）
- 三层架构：纯逻辑类（Student/ArtStudent/GradeSystem，类内零 IO）→ handler 函数（IO 层）→ main 分发
- 可变默认参数是共享陷阱：默认值必须不可变（`None` + 内部新建）
- 两层 try 分层：float 转换一层（"输入不合法"）、安检门 set_score 一层（`print(e)` 透传）——**不吞、不崩、透传**
- 添加原子性：全部 set_score 成功（else 分支）才 add_student——失败零污染
- 三引号字符串**逐字符收录**：代码块内缩进会爬进字符串内容（菜单缩进事故）
