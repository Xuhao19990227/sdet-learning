### 1. fake_api v3 + 状态计数器（逐字符照抄进 lesson3.py）

```python
api_state = {"query_calls": 0}


def fake_api(path):
    """模拟接口 v3：/query 是抖动接口——前 2 次调用返回 500，第 3 次起返回 200"""
    if path == "/query":
        api_state["query_calls"] += 1
        if api_state["query_calls"] <= 2:
            return 500
        return 200
    codes = {"/login": 200, "/pay": 500}
    return codes.get(path, 404)
```

### 2. 三个装饰器（你自己写——本题主体练习）

**① `timer(func)`——基础装饰器**
- 计时用 `time.time()`（或 `time.perf_counter()`），换算成毫秒保留 1 位小数
- 打印逐字符：`[timer] {func.__name__} 耗时 {cost:.1f} ms`
- **原函数抛异常时也必须打印耗时**——5.2 的四格里，哪个是清算区？
- 原函数的返回值透传；`@wraps(func)` 必写

**② `call_counter(func)`——闭包状态装饰器**
- 计数用**闭包 + 可变对象**（week4 可变默认参数一课的字典招式；禁 `global`）
- 每次被调用**先打印再执行**，逐字符：`[count] {func.__name__} 累计调用 {n} 次`
- 返回值透传；`@wraps(func)` 必写
- 不同被装饰函数的计数互相独立（闭包特性，导师边界会验）

**③ `retry(times)`——带参装饰器（三层）**
- 三层结构：参数层 → 函数层 → 调用层
- 只捕获 `AssertionError`（5.2 的精确捕获；别的异常一律不吞——导师边界会验）
- 每次失败打印逐字符：`[retry] {func.__name__} 第 {n} 次失败: {e}`（n 从 1 数起）
- 成功立即 `return`；`times` 次全失败则抛 `AssertionError(f"{func.__name__} 重试 {times} 次仍失败")`
- `@wraps(func)` 必写

### 3. run_case + 主流程（逐字符照抄）

```python
@timer
@call_counter
@retry(times=3)
def run_case(case_id, path, expected_status):
    """单条用例校验：请求 fake_api，断言状态码"""
    actual = fake_api(path)
    assert actual == expected_status, f"{case_id} {path} 期望 {expected_status} 实际 {actual}"
    return f"{case_id} PASS"


if __name__ == "__main__":
    print("=== TC001 稳定接口: 一次通过 ===")
    result = run_case("TC001", "/login", 200)
    print(f"结果: {result}")

    print("=== TC002 抖动接口: 重试 2 次后成功 ===")
    result = run_case("TC002", "/query", 200)
    print(f"结果: {result}")

    print("=== TC003 永败接口: 重试用尽仍失败 ===")
    try:
        run_case("TC003", "/pay", 200)
    except AssertionError as e:
        print(f"浅层捕获: {e}")
```

**内建自查信号**：三个标签里的 `func.__name__` 全都该显示 `run_case`——**只有三层装饰器都写了 `@wraps` 才会这样**。输出里哪一行出现 `wrapper`，就是哪一层身份证丢了。

### 5. 导师边界验收预告（写代码时心里有数）

import 无副作用（第 9 次实证）／`run_case.__name__` == `"run_case"`（@wraps 链）／retry 不吞非 AssertionError 异常（手动喂 ValueError 穿透不重试）／改 `times=1` 重试即变（参数驱动非写死）／call_counter 装饰两个不同函数计数独立。
