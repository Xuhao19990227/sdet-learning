## 数据源（逐字符照抄，放模块顶部）

```python
from datetime import datetime

CASE_RECORDS = [
    "TC001 | 2026-10-18 20:31:05 | 2026-10-18 20:31:07",
    "TC002 | 2026-10-18 20:31:10 | 2026-10-18 20:31:14",
    "TC003 | 2026-10-18 20:31:15 | 2026-10-18 20:31:18",
    "TC004 | 2026-10-18 20:32:00 | not_a_time",
]
TIME_FMT = "%Y-%m-%d %H:%M:%S"
TIMEOUT_SECONDS = 3
LOG_TIME = datetime(2026, 10, 18, 20, 31, 5)
```

每行记录格式：`用例编号 | 开始时间 | 结束时间`。

---

## A 部分：`parse_record(record)` —— split + strptime

把一行记录拆成结构化数据，返回字典（键顺序必须如下）：

```python
{"case_id": "TC001", "start": datetime对象, "end": datetime对象}
```

- 用 `record.split(" | ")` 拆三段；两个时间用 `datetime.strptime(s, TIME_FMT)` 解析
- **本函数不捕任何异常**——格式不对就让 ValueError 往上抛（纯逻辑层只说实话，分工见思考题 1）

## B 部分：`duration_seconds(record)` —— 异常在这里接

- try 里调 `parse_record`，算 `(end - start).total_seconds()` 返回 float
- **`except ValueError` 精确捕获**（5.2 姿势，禁裸 except），脏数据返回 **None**

## C 部分：`classify(cost)` —— 三分类纯函数

入参是 B 的返回值（float 或 None），返回字符串：

- `cost is None` → `"ERROR"`
- `cost > TIMEOUT_SECONDS` → `"TIMEOUT"`
- 其余 → `"OK"`（注意：**恰好等于 3.0 算 OK**，规格用的就是 `>`）

## D 部分：`make_report_name(dt)` —— strftime 反向

返回 `dt.strftime("report_%Y%m%d_%H%M%S.txt")`（格式串逐字符照抄）。

---

## 主流程（逐字符照抄）

```python
if __name__ == "__main__":
    print("--- 耗时报告 ---")
    for record in CASE_RECORDS:
        cost = duration_seconds(record)
        case_id = record.split(" | ")[0]
        print(case_id, classify(cost), cost)
    print("--- 报告文件名 ---")
    print(make_report_name(LOG_TIME))
```

注意主流程取 case_id 用的是 split 而不是 parse_record——想想为什么（脏数据行也要能打出 ERROR，思考题 1 会碰到这个分工）。
