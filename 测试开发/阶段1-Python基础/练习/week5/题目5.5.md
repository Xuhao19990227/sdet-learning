## 数据源（逐字符照抄，放模块顶部）

```python
LOG_LINES = [
    "2026-10-18 20:31:05 ERROR [pay_api] 连接网关超时",
    "2026-10-18 20:31:06 INFO [user_api] 登录成功",

    "2026-10-18 20:31:08 WARN [order_api] 响应慢2.3秒",
]

CASE_TEXT = "TC001 通过, TC042 失败, TC7 编号不合规, TC123 复测通过"
MODULE_TEXT = "错误来自 [pay_api] [user_api]"
```

---

## A 部分：`extract_case_ids(text)` —— findall + 精确次数

用 `re.findall` 提取所有**合规用例编号**：`TC` + **恰好 3 位数字**。返回字符串列表。

- 提示：模式 `r"TC\d{3}"`
- 自查信号：如果结果里出现 `TC7` → 你把 `{3}` 写成了 `+` 或 `*`

## B 部分：`parse_line(line)` —— compile + 分组提取

模块级编译（放函数外，只编译一次）：

```python
LINE_PATTERN = re.compile(r"^(\d{4}-\d{2}-\d{2}) (\d{2}:\d{2}:\d{2}) (\w+) \[(\w+)\] (.+)$")
```

函数接收一行日志，用 `LINE_PATTERN.search(line)` 解析，返回**字典**（键顺序必须如下）：

```python
{"date": ..., "time": ..., "level": ..., "module": ..., "msg": ...}
```

- 五个值分别来自 `group(1)` ~ `group(5)`
- 解析不出来（`search` 返回 None）时**返回 None，不许报错**
- **禁止用 split/index 拆字符串**——本课就是练分组

## C 部分：`extract_modules_greedy(text)` / `extract_modules_lazy(text)` —— 贪婪 vs 懒惰对照

从 `MODULE_TEXT` 提取方括号里的**模块名（不带括号）**：

- 贪婪版：模式 `r"\[(.+)\]"`
- 懒惰版：模式 `r"\[(.+?)\]"`
- 都直接 `return re.findall(...)`
