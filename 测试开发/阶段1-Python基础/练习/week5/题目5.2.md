## 一、背景（测试开发场景）

5.1 的校验器遇到一行脏数据（`expected_status="abc"`）会当场 ValueError 崩掉，**整批用例全部陪葬**。真实世界的测试数据天然是脏的——一条用例出错绝不能拖垮整批（pytest 的哲学：单条用例失败不停止整个套件）。本次改造：逐条**精确捕获**异常、标 ERROR、继续跑。

### 2. 自定义异常 + fake_api v2（逐字符照抄进 lesson2.py）

```python
class ApiNotFoundError(Exception):
    """自定义异常：接口路径不存在"""


def fake_api(api):
    """模拟接口 v2：未知路径抛自定义异常"""
    responses = {
        "/login": {"status_code": 200, "msg": "success"},
        "/pay": {"status_code": 500, "msg": "server error"},
        "/order": {"status_code": 200, "msg": "success"},
        "/cart": {"status_code": 200, "msg": "success"},
        "/logout": {"status_code": 200, "msg": "success"},
    }
    if api not in responses:
        raise ApiNotFoundError(f"未知接口路径: {api}")
    return responses[api]
```

### 3. 主流程要求

1. 读 `dirty_cases.csv`：`open(..., newline="", encoding="utf-8")` + `csv.DictReader`
2. **每条用例必须走 try/except/else/finally 四格结构**：
   - `try`：`int(row["expected_status"])` 转换 + 调 `fake_api(row["api"])`
   - `except ValueError` → 本条状态 = `"ERROR(数据非法)"`
   - `except ApiNotFoundError` → 本条状态 = `"ERROR(接口不存在)"`
   - `else`：只有 try 没出异常才进——比对状态码与消息，都对 = `"PASS"`，否则 = `"FAIL"`
   - `finally`：把本条结果（case_id + 状态）记入 results 列表——不管成败都要记账
3. 每条打印一行，逐字符：`{case_id} {状态}`（一个半角空格）
4. 汇总行逐字符：`共 6 条: PASS 3, FAIL 1, ERROR 2`——**三个计数全部动态算出，不许写死**（导师边界验收会改数据重跑；ERROR 数 = 两种 ERROR 之和）
5. 主流程放进 `if __name__ == "__main__":`——导师将 import 验证无副作用 + 跑边界
6. 本次**不写 report.json**（聚焦异常结构）
