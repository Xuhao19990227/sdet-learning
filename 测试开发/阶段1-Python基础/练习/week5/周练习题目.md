## 模块级常量（逐字符照抄，放文件顶部）

```python
import re
from datetime import datetime

LOG_PATH = "run_log.txt"
TIME_FMT = "%Y-%m-%d %H:%M:%S"
TIMEOUT_SECONDS = 3
LEVELS = ("ERROR", "WARN")
LINE_PATTERN = re.compile(
    r"^(?P<case_id>TC\d{3}) \| (?P<start>\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2})"
    r" \| (?P<end>\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2})"
    r" \| (?P<level>[A-Z]+) \| (?P<module>\w+)$"
)
```

## A 部分：`read_lines(path)` —— 生成器（5.4+5.1）

- `with open(path, encoding="utf-8")` 打开，逐行遍历
- 每行 `rstrip("\n")` 去掉行尾换行；**空行不 yield**
- 一次一行 **yield**——不许 readlines() 攒列表（5.4：惰性、拉动）

## B 部分：`to_record(line)` + `parse_all(lines)` —— 分组提取+异常分工（5.5+5.6+5.2）

**to_record(line)**：
- 用 LINE_PATTERN 匹配 line；**匹配不上 → return None**
- 匹配上 → 返回 dict，**键顺序固定**：`case_id`、`level`、`module`、`cost`
- `cost = (datetime.strptime(end, TIME_FMT) - datetime.strptime(start, TIME_FMT)).total_seconds()`
- **本函数不捕任何异常**——strptime 失败让 ValueError 往上抛（纯逻辑层只说实话，5.6 A 部分分工）

**parse_all(lines)** —— 生成器：
- 接收行流，逐行 `try: rec = to_record(line)` / `except ValueError: rec = None`
- `yield rec`——脏行 yield None，**流程不中断**（批量层逐条接住继续跑：5.6 Q3 的补层设计）

## C 部分：`filter_by_level(records, levels)` —— 生成器（5.4 回收）

- levels 参数驱动，**禁写死**（5.4 的原课教训）
- `rec is None` → **原样 yield**（脏行不归级别过滤管，计数责任在下游——思考题 1）
- `rec["level"] in levels` → yield；否则跳过

## D 部分：`classify(cost)` —— 四分类纯函数（你的设计落地）

- `cost < 0` → `"NEGATIVE"`（**你 5.6 Q3 设计的分类**）
- `cost > TIMEOUT_SECONDS` → `"TIMEOUT"`（**用常量，别手写 3——本周 F1 的教训，题目盯着呢**）
- 其余 → `"OK"`（恰好 3.0 算 OK，`>` 规格第三次登场）

## E 部分：`to_stats(items)` —— 单遍流式累加（5.4 Q3 回收）

消费记录流（含 None），**一遍循环累加，不攒 list**，返回 dict（**键逐字符**）：

```python
{"total": 非None记录数, "skipped": None个数, "timeout": TIMEOUT数, "negative": NEGATIVE数,
 "valid_sum": OK与TIMEOUT的耗时和, "valid_count": OK与TIMEOUT的条数,
 "max_case": OK与TIMEOUT中耗时最大的case_id, "max_cost": 最大耗时}
```

- **NEGATIVE 不参与 valid_sum / valid_count / max**——异常有自己的出口，不污染统计（你的 Q3 判断）
- max 初始：`max_case = "无"`、`max_cost = 0.0`；仅当 OK/TIMEOUT 且 `cost > max_cost` 时更新

## 主流程（逐字符照抄）

```python
if __name__ == "__main__":
    items = filter_by_level(parse_all(read_lines(LOG_PATH)), LEVELS)
    stats = to_stats(items)
    avg = stats["valid_sum"] / stats["valid_count"] if stats["valid_count"] else 0.0
    print("--- 日志分析报告 ---")
    print(f"匹配记录: {stats['total']}")
    print(f"跳过脏行: {stats['skipped']}")
    print(f"超时: {stats['timeout']}")
    print(f"负耗时: {stats['negative']}")
    print(f"平均耗时: {avg:.1f}s")
    print(f"最耗时: {stats['max_case']} ({stats['max_cost']:.1f}s)")
```

## 自查信号

- 「跳过脏行: 0」= 正则太松（把坏行也匹配了）或 parse_all 没在数
- 崩溃 ValueError = parse_all 没接住（或 to_record 偷捕了 = 违反分工）
- 「超时: 2」= 把 INFO 的 TC008 数进来了（过滤没生效/LEVELS 写错），或把恰好 3.0 数进去了（`>` 写成 `>=`，第三次）
- 「平均耗时: 2.0s」= 把 NEGATIVE 算进了平均（(3+1+5+3-2)/5=2.0；正解排除负数=3.0）
- ZeroDivisionError 崩 = avg 没做除零保护
