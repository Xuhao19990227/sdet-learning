## 背景场景

你是测试组的工具开发：接口自动化跑完会产出结果文件（每行：`用例ID,状态,耗时秒`），
组里需要一个「读结果文件 → 统计 → 出报告」的工具模块。要求封装成可复用模块——
别的脚本 `import` 它时只拿函数，不触发主流程。

## 样例数据（一字不差）

主流程先用 `write_lines` 把它写成 `results.txt`（10 条）：

```
TC001,PASS,1.2
TC002,PASS,0.8
TC003,FAIL,3.5
TC004,PASS,2.1
TC005,FAIL,5.0
TC006,PASS,1.5
TC007,PASS,0.9
TC008,FAIL,2.8
TC009,PASS,1.1
TC010,PASS,3.2
```

## 必备函数（签名与返回结构必须一致，内部实现自由）

1. `write_lines(path, lines)` —— 把字符串列表逐行写入文件（自动补 `\n`），无返回值
2. `read_lines(path)` —— 读文件，返回去掉换行符的行列表
3. `parse_records(lines)` —— 用 **map** 把每行解析为元组 `(用例ID, 状态, 耗时)`，耗时必须是 float
4. `find_failed(records)` —— 用 **filter** 筛出状态为 `'FAIL'` 的记录
5. `summarize(records)` —— 返回字典：
   `{'total': int, 'passed': int, 'failed': int, 'pass_rate': float, 'avg_duration': float}`
   - pass_rate 为百分数数值，保留 1 位小数（本组数据应为 70.0）
   - avg_duration 保留 1 位小数（本组数据应为 2.2）
   - ⚠️ **除数必须用 len(records)，不许写死**（错题本第 8 条盯过你）
6. `format_report(summary, failed)` —— 返回报告行列表（字符串 list），必须包含：
   - 总数 / 通过数 / 失败数 / 通过率 / 平均耗时
   - 每条 FAIL 一行，格式 `序号. 用例ID(耗时s)`（如 `1. TC003(3.5s)`）——
     序号用 **enumerate**（start=1），ID 与耗时的配对用 **zip** 完成
7. 主流程放进 `if __name__ == '__main__':`：
   生成 results.txt → read_lines → parse_records → find_failed + summarize →
   format_report → 用 write_lines 写 `week3_report.txt` → 读回打印全文

## 终端输出必须包含的数据（排版自由，数字必须准）

- 统计：共 10 条 / 通过 7 / 失败 3 / 通过率 70.0% / 平均耗时 2.2s
- FAIL 明细 3 条：TC003(3.5s)、TC005(5.0s)、TC008(2.8s)，序号 1/2/3
- 最后打印 week3_report.txt 全文
  （可加 `--- week3_report.txt 内容 ---` 之类的分隔标记，**标记只 print 到终端，不许写进文件**——热身练习第 3 轮的教训 😉）
